# Imagenes de productos

Estas rutas deben contener los assets retail usados por el catalogo:

- `vestido_midi.jpg`
- `pendientes_corazon.jpg`
- `top_tirantes.jpg`
- `falda_midi.jpg`
- `vestido_vidi_terciopelo.jpg`
- `guantes.jpg`
- `vestido_terciopelo.jpg`
- `pendientes_piedras.jpg`
- `demo_dress.svg`
- `demo_jacket.svg`
- `demo_trousers.svg`
- `demo_blouse.svg`
- `demo_skirt.svg`
- `demo_bag.svg`
- `demo_belt.svg`
- `demo_sunglasses.svg`
- `demo_hat.svg`
- `demo_necklace.svg`
- `demo_bracelet.svg`

Los ficheros `demo_*.svg` son placeholders locales de despliegue y pruebas para nutrir el catalogo sin depender de fotografia adicional.

Si falta algun archivo fotografico, copia la version retail de referencia a esta carpeta.

Tambien puede existir una carpeta `variants/` con un primer lote de variantes de color demo generadas localmente a partir del asset original.
Estas variantes sirven para probar el pipeline de `colorVariants`, pero no sustituyen a fotografia retail final por color.
